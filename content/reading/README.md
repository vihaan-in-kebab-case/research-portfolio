Frontmatter used by app/reading (one collection for everything you read —
quick log entries and full critical-analysis notes both live here):

---
title: ""
domain: ""
difficulty: ""      # e.g. intro, intermediate, advanced
date: ""             # used for sorting
date_read: ""        # optional, shown if different from date
time_invested: ""
key_takeaway: ""     # shown as a pull-quote on the detail page
related: ""
status: ""           # e.g. read, in-progress, revisit
deep_dive: ""        # true or false for explicit marking

# Add these three to mark an entry as a "deep dive" — it gets a badge on
# the list page and shows a citation line instead of domain/status:
authors: ""
venue: ""
year: ""
---

For a deep-dive entry, write the body with these headings: Research
problem, Key contribution, Strengths, Weaknesses, Assumptions, Connections
to other papers, Questions I still have, Ideas inspired by this work.

For a quick log entry, `key_takeaway` alone is enough — leave the body
empty or add a couple of informal sentences.
