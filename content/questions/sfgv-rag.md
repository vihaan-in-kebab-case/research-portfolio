# Why it interests me:
The goal with this question is to explore whether using dynamically constructed knowledge graphs can improve the factual reliability of retrieval-augmented generation systems. This involves using an LLM to extract entities and relations from retrieved documents, constructing a graph, and investigating whether this graph helps the LLM identify, connect, and verify supporting evidence for its response.
